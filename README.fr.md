# Hangar

Tous les jeux de votre Mac dans une seule bibliothèque : les jeux Mac, et les jeux Windows qui s'exécutent dans CrossOver et d'autres lanceurs. Hangar les trouve, les lance, et garde leurs réglages et leurs sauvegardes en sécurité.

Hangar en est à ses débuts : la version 0.1.0 est une fenêtre avec un aperçu et un journal. La suite est dans [docs/STORIES.md](docs/STORIES.md).

**[Télécharger Hangar](https://github.com/matguitarist/Hangar/releases/latest/download/Hangar.dmg)** · macOS 26 ou plus récent, Apple Silicon.

## Compiler

```zsh
./build.sh --open
```

Compile avec Swift 6 et installe `~/Applications/Hangar.app`. `swift test` lance les tests.
