# Hangar glossary

One name for each thing, in every button, menu, title, tooltip and error.

| Term | Means | Not | Français |
| --- | --- | --- | --- |
| Game | Anything in the library you can play: a Mac app, a Steam game, a Windows program | app, title, entry | jeu |
| Library | Every game Hangar knows about | collection, catalog | bibliothèque |
| All Games | The sidebar page with the whole library | Home, Library page | Tous les jeux |
| Source | Where Hangar found a game: Steam, CrossOver, Mac Apps, Added by You | store, provider | source |
| Collection | A list of games the person makes | folder, category, tag, playlist | collection |
| Runner | What runs a game: Mac (native), CrossOver, Wine, Game Porting Toolkit, MacRunner | engine, compatibility layer, launcher | lanceur |
| Bottle | A CrossOver bottle: a Windows setup where Windows games are installed | prefix (except for Wine runners), container | bouteille |
| Prefix | A Wine or Game Porting Toolkit folder that holds a Windows setup | bottle | préfixe |
| Windows game | A game that runs through a runner other than Mac | PC game, .exe | jeu Windows |
| Launch options | A game's own program, arguments and environment variables | command line, flags | options de lancement |
| Graphics | The way a Windows game's graphics reach Metal: Auto, D3DMetal, DXMT, DXVK, Wine | backend, renderer | graphismes |
| Runs on a Mac | AppleGamingWiki's verdict for each way to play a game on a Mac | compatibility, rating | Fonctionne sur Mac |
| Recommended Setup | A recipe as the game page shows it | recipe, fix | Configuration recommandée |
| On the Web | The game's pages on the wikis, CodeWeavers, ProtonDB and its store | links, resources | Sur le Web |
| Recipe | The known-good setup for a game: runner and settings | profile, preset, fix, config | recette |
| Recommended setup | A recipe offered for a game on its page | best settings | configuration recommandée |
| Snapshot | A saved copy of a game's settings and bottle files, to roll back to | backup (that's for saves), restore point | instantané |
| Save backup | A copy of a game's saves | snapshot, cloud save | sauvegarde de la partie |
| Playtime | Total time a game has run from Hangar or Steam | hours, time played | temps de jeu |
| Play | Start the game | Launch, Run, Start | Jouer |
| Stop | Quit a running game from Hangar | Kill, Force Quit, End | Arrêter |
| Running | A game that is open now | Playing, active | En cours |
| Remove from Library | Take a game out of Hangar; its files stay on disk | Delete, Uninstall | Retirer de la bibliothèque |
| Couch mode | The full-screen view used with a controller | Big Picture, TV mode | mode salon |
| Battery settings | A game's other settings used when the Mac is on battery at launch (the On Battery section) | battery profile, power plan, eco mode | réglages sur batterie |
| Low Power Mode | macOS's own power-saving mode; Hangar only suggests it | power saving, eco mode | mode Économie d’énergie |
| Menu bar icon | Hangar's gamepad in the menu bar: running and recently played games | status item, tray icon, widget | icône de la barre des menus |
