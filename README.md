# Hangar

Every game on your Mac in one library: Mac games, and Windows games that run through CrossOver and other runners. Hangar finds them, launches them, and keeps their settings and saves safe.

Hangar is at its very start: version 0.1.0 is a window with an overview and a log. What comes next is in [docs/STORIES.md](docs/STORIES.md).

**[Download Hangar](https://github.com/matguitarist/Hangar/releases/latest/download/Hangar.dmg)** · macOS 26 or later, Apple Silicon.

## Build

```zsh
./build.sh --open
```

Builds with Swift 6 and installs `~/Applications/Hangar.app`. `swift test` runs the tests.
