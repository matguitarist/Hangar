# Sample library

Copied from the layout of a real Mac: a Steam folder with two library folders (one on a drive that isn't connected), CrossOver bottles, Mac apps, and the games Heroic installed (`Heroic/` names them, `Games/` holds them).
The self-test and snapshot mode copy this folder to `<store>-run/fixtures` in /tmp and replace @ROOT@ with that folder. Unit tests read it in place.
