# Game details answers

What the Steam store and TheGamesDB answer, read by the unit tests, the self-test and snapshots instead of the network (`GameDetailsCache.folder`). `steam-367520.json` is Hollow Knight's real appdetails answer, trimmed (2026-11-24). The TheGamesDB files are made up for the sample game Moonlit Harbor: `tgdb-<title>.json` is a ByGameName search, `tgdb-Genres.json`, `tgdb-Developers.json` and `tgdb-Publishers.json` the name lists. `steam-1546710.json` is made up for Vernal Edge, with a Mac version. `appstore-<title>.json` is a Mac App Store search (made up for Starfall Arcade, with a second app of a longer name that must not match).
